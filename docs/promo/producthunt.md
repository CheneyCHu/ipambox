## Description (260 字符内)
IPAMBox is a lightweight, open-source IP address manager for small networks. Single binary — runs on a Raspberry Pi. A live grid map shows every IP at a glance; it detects conflicts and rogue devices, keeps an inventory, works fully offline, and has a built-in AI assistant. Bilingual UI (CN/EN).

## First Comment（发布者自己发的第一条评论）
Hi Product Hunt 👋

Maker here. I built IPAMBox after watching small teams manage IPs in Excel and only discover conflicts when something broke.

Design goals:
1. **Zero-setup** — one binary, no database, no web server config. A 3-step wizard gets you from unboxing to scanning in a minute.
2. **Visual** — the whole subnet as a color-coded grid instead of endless tables.
3. **Autonomous** — it keeps scanning and logging even when the internet is down, queuing notifications until recovery.
4. **AI-ready but private** — ask questions in plain language; point it at a local Ollama and nothing leaves your network.

It's open source (GitHub link above), v1.0.2, with one-line install for Linux/macOS/Raspberry Pi. I'd love feedback from anyone running a homelab or managing an office network. AMA!
