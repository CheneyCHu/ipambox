## 标题
[开源] IPAMBox：插上网线就能用的 IP 地址管理盒子，树莓派可跑

## 正文
做这个东西的起因：小公司没有专职网管，IP 全靠 Excel 记，冲突了才知道被占了。看了圈现有方案，phpIPAM 要 LNMP 全家桶，商业硬件又贵，就自己写了一个。

**IPAMBox** 是一个开源的轻量级 IPAM（IP 地址管理），特点：

- 单二进制，前端嵌在后端里，一键安装脚本搞定（curl | bash），树莓派就能跑
- 首次启动 3 步向导：设密码 → 点选本机网卡自动组网 → 开扫
- IP 网格地图：整个网段 254 格一页看完，在线/离线/闲置/冲突/保留/未授权六种颜色，鼠标悬停显示详情
- MAC 漂移检测 IP 冲突；发现未登记设备自动标记"未授权"
- 断网续存：外网断了本地功能照常用，通知排队，恢复了自动补发（设计给放机房角落的场景）
- 内置 AI 助手：自然语言问"192.168.1.50 是谁在用"，可以接 DeepSeek 或本地 Ollama（数据不出内网）
- OTA 在线升级，不用 SSH 上去换文件
- 中英双语、钉钉/企微/Webhook 通知、只读账号（给领导看）、CSV 台账导入导出

技术栈：Go + SQLite（WAL）+ Vue3 + Tailwind，81 项自动化 E2E 测试。

截图和安装说明都在 README：
https://github.com/CheneyCHu/ipambox

目前 v1.0.2，欢迎试用拍砖。有真实局域网环境的老哥帮忙测测 Linux/ARM 下的扫描效果就最好了。
