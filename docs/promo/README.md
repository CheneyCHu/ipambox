# IPAMBox 推广方案

> 版本：2026-08-16 ｜ 仓库：https://github.com/CheneyCHu/ipambox

## 一、定位与核心卖点（所有文案的素材库）

**一句话定位**：插上网线就能用的 IP 地址管家盒子 —— 面向中小企业的轻量级开源 IPAM。

**差异化卖点（对 phpIPAM / 传统运维系统）**：
1. **零门槛**：单二进制、一键安装、3 步向导自动组网，不用配 Nginx/MySQL/PHP
2. **IP 网格地图**：整个网段一页尽收眼底，闲置/在线/离线/冲突/保留/未授权六种状态色块
3. **断网续存（边缘自治）**：外网中断时本地扫描台账照常，通知排队恢复后补发
4. **AI 助手**：自然语言查 IP、问冲突，支持 DeepSeek/本地 Ollama（数据不出内网）
5. **OTA 在线升级**：设置页一键检查更新，SHA-256 校验，自动重启
6. **低成本硬件**：树莓派即可跑，SQLite 免运维
7. 中英双语、Webhook/钉钉/企微通知、只读账号、CSV 台账导入导出

**目标用户**：中小企业运维/网管、工作室/实验室管理员、软路由/家庭实验室玩家、MSP。

**CTA（行动号召）**：GitHub Star + 一键安装试用 + Issues 反馈。
