# Security Policy / 安全政策

## Supported Versions / 支持的版本

Only the latest release receives security fixes. Please upgrade via
Settings → System Update (OTA) or download the newest Release.
只有最新版本会获得安全修复，请通过 设置 → 系统升级（OTA）或下载最新 Release 保持更新。

## Reporting a Vulnerability / 报告安全漏洞

**Please do NOT open a public GitHub Issue for security vulnerabilities.**
**请不要通过公开的 GitHub Issue 报告安全漏洞。**

Please report privately by email / 请通过邮件私下报告：

- Email / 邮箱：**cheneychu@qq.com**

Please include / 请尽量包含：

- Affected version(s) / 受影响的版本
- Steps to reproduce or proof of concept / 复现步骤或概念验证
- Potential impact / 潜在影响

You will receive an acknowledgement within 72 hours. Once confirmed,
a fix will be released and credited (unless you prefer to stay anonymous).
我们会在 72 小时内确认回复。漏洞确认后会尽快发布修复版本，并在更新说明中致谢（除非你希望匿名）。
